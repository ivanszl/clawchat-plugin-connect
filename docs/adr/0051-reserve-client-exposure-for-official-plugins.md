# Reserve Client Exposure for official Plugins

Client Exposure remains a privileged capability available only to official Connect Plugin Bundles; the public Plugin SDK initially exposes Runtime Adapter and Client Extension contributions. A generic Exposure can reach the loopback Shared Client Gateway but cannot prove an authenticated remote principal, owner, freshness, or replay resistance to Core, so allowing third-party publishers would turn network reachability and Plugin correctness into authorization for the installation-wide Client, including Plugin administration. Liveware is accepted as a narrow official integration because its private ClawChat launcher and WebView ticket flow are owned and qualified with the release. A public Exposure seam may be reconsidered only when Core can independently verify a short-lived, audience-bound admission proof instead of trusting forwarded headers or the publishing Plugin.
